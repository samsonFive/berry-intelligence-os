# Product Visual System V1

Standalone interactive style-guide prototype. Unifies the successful Daily Briefing / Competitor Landscape / Trust Controls visual language.

## Quick start

```bash
cd prototypes/product-visual-system-v1
python3 -m http.server 8770 --bind 127.0.0.1
# open http://127.0.0.1:8770/
```

## Contents

| Path | Purpose |
|---|---|
| `index.html` | Interactive style guide |
| `styles.css` / `guide.js` | Presentation + demos |
| `tokens/` | Design tokens (CSS + JSON) |
| `docs/COMPONENT-CATALOG.md` | Per-component contracts |
| `docs/IMAGERY-FALLBACK-POLICY.md` | Honest media rules |
| `docs/MIGRATION-MAP.md` | Staged adoption order |
| `docs/ACCESSIBILITY-CHECKLIST.md` | A11y checks |
| `docs/CHECKPOINT.md` | Freeze notes |
| `docs/CONTINUATION-PROMPT.md` | Next production prompt |
| `verification/` | Screenshots + video |
