# Registry-code photos and original Canadian records

Four source-labeled photographs for strawberry ASF218 and ASF219 now reach the
private review gallery, alongside their original Canadian registry links. The
registry pairs these codes with Ava Blush and Ava Star. Existing uncoded AVA
entries remain separate pending human identity review; viewing a code-labeled
photo does not confirm that pairing or create a catalog variety.

## What changed

The gallery previously withheld every photo when a source's code/trade-name
pairing needed review. A private candidate whose name and recorded code both
match the photo's exact source code can now show that source reference. The
photo, candidate and reference must have the same berry, and the photo's source
URL must equal the recorded name reference. Trade-label photos, different codes,
different crops and different source URLs remain held by the identity guard.
Canonical profiles retain the existing pairing/ambiguity gate.

Each photo starts unloaded with **Ignore permission** for a single tab-session
preview and **Hide photo** to reverse it. Credit, caption, original source and
unconfirmed reuse remain visible. No persistent permission or public image
publication is approved. Browser acceptance also found and repaired tall images
overlapping captions: images now fit a bounded frame, and an explicit Show
action brings the whole chosen card into view. Restoring a prior session or
hiding an image does not trigger that navigation.

Two bounded source sections and two additive registry-import rows retain the
source-reported application, grant and surrender information. The 2024-02-04
rights-surrender date and compulsory-licensing exemption expiry are separate;
neither is written as patent/PBR expiry. Both rechecked pages displayed
2023-09-18 as modified, while an earlier ASF219 capture displayed 2026-10-01.
Those observations stay explicit rather than becoming a freshness conclusion.
Seven comparator-name occurrences are accounted for as exclusions from these
two focal registrations; they do not establish applicant ownership. Trial and
office locations do not establish growing regions. No alias, party role,
trait, legal status or Source collection onboarding is approved.

Original sources: [ASF218](https://active.inspection.gc.ca/english/plaveg/pbrpov/cropreport/str/app00011776e.shtml)
and [ASF219](https://active.inspection.gc.ca/english/plaveg/pbrpov/cropreport/str/app00011777e.shtml).
Metadata is in the existing dated imports; the existing
`scripts/import_variety_universe_pilot.py --fixture` workflow supports the new
registry-row file. It never creates canonical entities and preserves existing
private rows on replay. Source tier denotes provenance, not human approval.
