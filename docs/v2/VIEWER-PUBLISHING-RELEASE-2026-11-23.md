# Export to viewer platform release

The publishing workspace is available at /viewer when the release is deployed. It provides release preparation, a durable latest-package download, an authenticated research preview, publishing instructions, corporate settings/project templates, a company ID lookup and the starter kit. The main navigation links to it from both server-rendered pages and the persistent application shell. All links and files remain behind existing platform authentication and authoring controls.

The corporate output remains HTML with inline CSS and no JavaScript/API calls. Tier assignments, projects and flavor stay corporate-side. Reports are explicit selections in the platform release form. Private account exports and previews do not enter the public static build.

Release acceptance requires successful current-head Change scope, Frontend validation, Repository integrity, Static public safety and Python tests checks. Deployment must preserve the existing production image's unrelated changes, native assets, mounts, settings, private reports and runtime data. The private operational receipt records the actual deployed image, rollback source, preservation backup and live authenticated checks. Until that receipt is complete, this document is a release description, not a claim of deployment.
