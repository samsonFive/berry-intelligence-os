## Source-scope correction

Shared News only checked explicit IDs, so those articles disappeared from company News, company/list/favorite/tier filters and Digest subscriptions. A small adapter now reuses that conservative matcher for selected/subscribed company scopes. It searches source metadata only, excludes unreviewed/live/automatic-unvalidated sources from fallback and refuses to infer provisional photo identities. Existing explicit associations remain available in the raw lane.

Cards distinguish **Mentioned in source** from reviewed company links. Original IDs, URLs, source files and article/transcript bodies remain unchanged. A mention does not create a relationship, approve an identity, promote a source, create a statement or alter packet matching. Trusted News still requires its original active escalated statement; newest publication remains first. Unfiltered News does not scan all companies for fallback.

Digest says **Source reviewed** using the actual shared source predicate. A saved live or automatic-unvalidated record remains **Unreviewed**, even if its old status says published. Saving, subscriptions, reading progress and source review remain independent.
