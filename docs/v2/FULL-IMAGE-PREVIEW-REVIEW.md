# Larger filing images without losing user edits

Four earlier original filing references used thumbnails. ABB 132, ABB 135,
ABB 136 and ABB 128 now have checked larger originals available for the existing
session preview. Their named figure labels, original document association,
monochrome reproduction, credits and unconfirmed reuse status remain visible.

Changing an image URL would change its generated source-photo ID, disconnecting
saved captions, image replacements, hidden-photo choices and history. Instead,
an additive, fingerprint-guarded presentation overlay supplies a larger preview.
The original image URL, photo ID and editable source details remain unchanged.
User overrides take precedence; hide, restore and reset still use the same ID.
A newer or operator-edited source capture wins over the overlay. Warning and
image overlays independently guard the same original capture.

Only an explicit session choice loads the larger held image. No image acquisition
runs on a page request. Nothing changes reuse permission, identity, aliases,
company roles, growing regions, current rights or publication review. Private
photo details remain excluded from static/public output. This generic metadata
and rendering change introduces no crop-specific branch or canonical schema.

The four source HTML captures and original PDFs were already retained. Their
explicit full-image URLs were extracted without guessing. All four larger
figures were downloaded and visually inspected. Their source dimensions range
from 909 × 1792 to 1427 × 1981. Initial local size validation was too strict for
two widths below 1000; two retained successes were reused and two discarded
responses recaptured. This is not a source access failure. Raw bytes and receipts
remain private; the import contains metadata only.

No source or name is added: the bounded corpus remains 484 sections and 1,757
name occurrences. The public 64-profile research seed still has 15 image-reference
gaps; live production has 65 profiles and must not be replaced by that seed.
Historical grants and monochrome figures do not establish commercial success,
approved brand aliases, current rights or reusable color photography.

Validation covers source fingerprints, simultaneous warning/image overlays,
unchanged photo IDs, saved user replacements, captions, hide/restore/reset history,
wrong crop/name/source rejection, session consent and static exclusion. Browser
review and current-head required checks precede any separate catalog release.
Frozen #422 has 5,305 passing tests. Platform #421 and its pending actual release
approval remain separate; this change inherits no deployment or preservation proof.

CAT-01/CAT-02 and TD-116 remain open for broader current/historical catalog
coverage, source/identity decisions, independent human recall, current rights,
attributed color photos and the remaining reference gaps.
