# News visual coverage

Prefer the publisher's article image. Scheduled News collection now attempts up to 12 missing thumbnails across the first 108 eligible records per run, using existing public-page metadata fetching, four workers and the reader's existing request/response bounds. Failed attempts retain the existing 24-hour retry boundary. Manual page-specific image loading remains available. Page views never fetch publisher metadata. No paywall, authentication or hotlink barrier is bypassed, and publisher images are not copied into the reusable reference catalog.

When a source photo is absent or fails in the browser, the shared card/Reader visual uses a locally served reference photograph. The initial catalog has 24 individually reviewed crop, mixed-berry and plant-research photos. The catalog records each source's public-domain or CC0 designation, creator, file-description/licensing link, original/download URLs, review date and downloaded-file SHA256. Source licensing assertions are documented; this is not a warranty about all possible rights. The original-source/creator links remain visible on each reference caption. USDA's non-endorsement condition applies. No identifiable portraits, branding, historical seed-catalog scans, unrelated desserts, or ambiguous ornamental-flower photos were admitted.

Reference selection favors crop wording in original title/summary, then existing crop assignments, then generic mixed-berry context where the crop is unknown. Research scenes are reserved for research context. A page-level allocator prefers less-used eligible assets to reduce repetition. Reference visuals are labeled **Reference photo** and do not depict the reported event, establish a cultivar's identity, locate an operation, or strengthen evidence/trust. They are kept separate from the publisher image URL, so a real source image always wins. Different filtered pages may select different equally relevant reference photographs; source identities and stored records are unchanged.

The local catalog continues working when external publisher images are blocked. A missing local asset falls back to a compact source label. Reference photo bytes are shipped with the reviewed application image; no runtime image-generation service, paid media service, or browser-time image search is introduced. Existing generated illustrations remain archived assets but are not used by this fallback policy.

Source policy references: [USDA ARS photo-use terms](https://www.ars.usda.gov/oc/images/copyright/) and [Commons reuse guidance](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia). Exact per-file evidence is in `app/static/news-images/reference-catalog.json`. The fixed 14-day News pilot, local translation policy and mandatory human review gates remain unchanged. Scheduled receipts record image attempts and successes separately from article counts; image failures do not change a publication's relevance or trust.
