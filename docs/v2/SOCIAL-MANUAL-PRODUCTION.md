# Manual Social Listening collection

The operator approved one $29 SociaVault pack on October 12, 2026 and purchased it directly. An authenticated account read confirmed 6,010 credits. Corporate-system integration APIs are deferred to a later sprint. The existing private workspace endpoints support the app itself; they are not a supported external API contract.

Opening the workspace, changing filters, previewing a collection or viewing job history never initiates source requests. **Collect fresh posts → Preview update → Collect now** explicitly queues a bounded background job. Users can choose berries, corporate/agtech or consumer scope, supported platforms, and the past week/month. Repeating the same choices within 24 hours reopens the prior job without spending again. There is no timer or collection on page load. Polling job status is read-only and ends after completion or 15 minutes.

SociaVault is the discovery provider. Apify remains available through the separately guarded explicit detail runner within its verified free allowance; this UI does not automatically launch paid Actors. Facebook is retrieval from the two previously demonstrated Fall Creek and Driscolls company pages, not arbitrary keyword/global search. Instagram is hashtag discovery, not corporate phrase search. Dates are provider-dependent and may reflect an index window; exact historical recall is not claimed. Each query retrieves one page with the existing ten-record normalization cap. Platform failures and mapping errors remain visible and never become zero-volume success.

## Operator configuration

Set `BIOS_SOCIAL_MANUAL_COLLECTION=true`, `SOCIAVAULT_API_KEY` privately, and `BIOS_PUBLIC_ORIGIN=https://intel.johnnyaceii.com` in the production deployment environment. The exact configured public origin protects mutations behind the existing TLS proxy; arbitrary forwarded headers are not trusted for this check. Keep credentials out of Git, build context, browser JavaScript, reports and source URLs. Compose defaults collection off. The pipeline registry records this manual lane separately with scheduling disabled.

The shared runtime lease is `inbox/operations/collection.lock`. Durable reservation ledger is `inbox/social/manual-credit-ledger.json`; jobs use the existing private social SQLite index. Bounds: 40 requests/update, 200 reserved requests/month, 1,000 reserved requests for this policy lifetime, and a 100-credit account reserve. Reservations are written before transport and retained after ambiguous failures. Account credits are freshly checked before/after each request. Unexpected costs halt later collection for operator review. No automatic retries, balance top-ups, purchase endpoints, or paid fallback exist. Default all-berry/both-scope plan costs at most 26 reserved credits. Cost is credits per request, not per retained post; actual independent usefulness is measured separately.

Interrupted queued/running jobs require operator investigation; the app never retries an uncertain charge automatically. Inspect the job, credit ledger and source receipts under a runtime lock, then explicitly reconcile its status before another run. Do not delete/reset the ledger to obtain another allowance. Locks from other acquisition pipelines are respected.

## Intake and display

The established provider normalizer, source/native-ID/mode identity, SQLite intake, deletion tombstones, evidence extraction, and media-reference handling are reused. No canonical evidence promotion, new identity graph, OCR or media rehosting is introduced. Previously reviewed language/role/translation is preserved only for identical text and absent incoming classification. Changed original text is not given a stale translation.

Missing language can receive a proposed English label using the offline langid 1.1.6 classifier, only for captions of at least 15 words with model score >=0.99. Its recorded basis explicitly identifies the model and lack of independent grading. This score is not measured accuracy. Other languages and ambiguous captions remain pending; no source text is sent to a translation service. Readability controls still exclude posts without English wording or translation. Conservative literal topic/first-person/recipe rules can propose trade, consumer or recipe labels; query scope never establishes author identity, geography or berry relevance.

## Validation and rollback

Offline tests cover disabled configuration, unsupported options, duplicate/restart reuse, pre-request reservations, credit reserve/monthly caps, unexpected cost halting, outage versus zero, fixture isolation, preserved reviewed labels, five-language/short-caption rejection, authentication, CSRF and the explicit TLS-proxy origin. Live collection receipts remain private and are reported separately from synthetic tests.

To disable new collection, set `BIOS_SOCIAL_MANUAL_COLLECTION=false` and recreate only the app service. Keep existing data, SQLite jobs and ledger for audit. There is no structural SQLite migration; reverting UI/service changes does not require deleting collected evidence. The pinned language dependency is additive to both development and web images. Production rollout requires the repository's exact-head CI gate, a fresh runtime/config backup, and authenticated public HTTPS validation with existing pages preserved.

One-credit assumptions remain guarded against actual account deltas; a vendor claim does not qualify coverage or redisplay rights. [Offline language identifier](https://github.com/saffsd/langid.py).
