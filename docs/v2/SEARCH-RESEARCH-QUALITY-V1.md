## Implementation

`topic_retrieval.py` is a network-free shared lexical/concept and passage service. It preserves raw wording, quoted phrases, exclusions, names and explicit publication dates; handles narrow domain variants and the second-year-cane paraphrase; retains parent IDs and passage locators; uses only evidence-linked stored fruiting-habit traits for trait-only matches; and separates direct, background and adjacent matches. A primocane release is adjacent to a floricane question unless its floricane-crop trial context supports direct relevance. This is bounded vocabulary expansion, not general semantic/vector retrieval.

The feed, older archive filter, Global Search and Research Desk reuse this understanding where their contracts permit. Report topics scan supplied accessible records including pending publication records, with visible trust classes. Explicit entity/geography/date constraints survive retrieval. News browsing's date/read/page filters do not enter a new report. Selected-material Living Workspace generation was not changed.

`topic_discovery.py` uses the existing Perplexity Search client and public reader, with a provider-injectable client for tests. It performs at most four raw/interpreted/development variants plus two registry-name follow-ups actually justified by discovered titles, then at most forty bounded source captures. No fixed answer URLs, deep-research model, new subscription, publisher subscription or trusted intelligence mutation is added. Successful requests cache for thirty minutes under private `inbox/`; failures remain retryable. Canonical URLs and exact captured-body hashes deduplicate copies. Distinct source/version/milestone records are retained. This does **not** solve general syndicated-event clustering.

The report confirmation screen shows interpretation, original-wording control, effective filters, full-archive candidate/body counts, local/web split, capture health, source dates, passages and provider state. Combined scope explicitly names Perplexity Search and what is sent. Archive-only performs no web request and offers a visible scope change. Missing credentials and provider failures produce coverage reasons, never a conclusion that no developments exist.

Report output is conservative, deterministic attributed source prose. Search snippets and stored metadata alone cannot become inspected source claims. Neighboring release/licensing context is retained with its locator. This preserves the repository's existing model-export boundary: article bodies, private Facts/Signals/Assessments and analyst notes are not sent to a model. The private report saves the matched source versions, retrieval provenance and effective scope. Reload does not rebuy research. A selected source excerpt can enter the existing workspace capture/knowledge store, with an exact locator and `unverified` state; repeated capture is idempotent. No trust gate is bypassed.

Automatic approval review rejected background web discovery on page load because it could send free-text questions and registry names externally without a per-request destination choice. The implemented Research Desk retains an explicit, described web action. Do not enable automatic page-load queries through another route as a workaround.
