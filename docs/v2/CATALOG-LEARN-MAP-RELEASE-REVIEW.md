# Catalog, visual Learn and Map release candidate

This candidate reconciles the tested catalog/photo/source stack and drafts
#435–#439 with deployed canonical `6fe8bdeb`. It retains platform #433 and the
subsequent News Tags release. It is a new combined acceptance check, not a
deployment of an older catalog image or an answer to an older approval question.

## What changes

- Variety profiles and candidate sources gain original filing, claim and figure
  links, attributed photo leads, clearer identity holds and separate related
  rights records. Photo and coverage preparation share their existing checks
  within each request. Human edits, hidden photos and saved review choices win.
- Original company releases, historical registers and research papers become
  additional source material for the catalog review queue. A visible name
  does not silently become an approved identity, breeder role or current right.
- All 27 existing Learn lessons have interactive explanations. New schematics
  describe mechanisms, not measured crop performance; photographs retain their
  individual attribution and reuse basis. A narrowly matched clarification of
  double-cropping wording preserves the original record and any user edit.
- Map research uses existing country selectors. France's missing boundary
  metadata is corrected without editing geometry. The explicit Eurostat check
  proposes seven strawberry countries; figures reach the shared Map only after
  selection and saving. Snapshot PDFs retain the selected country, source units,
  annual period, original source link and a separately labeled dataset update.

The original accepted requirements and all human source, identity, claim,
catalog, current-rights, qualification and photo-use decisions remain separate.
The public baseline has 64 variety profiles; production has its own additional
records and edits. Neither a public seed nor a review copy may replace them.

## Acceptance evidence

Earlier component results establish their own scope: #439 passes all four checks
and 5,455 tests, with desktop/412px and rendered-PDF review. These results do not
prove this new combination. Its current head needs:

1. Required Change scope, Repository integrity, Static public safety and Python
   checks, plus tests covering the platform/catalog/Tags integration boundaries.
2. Native desktop and phone review of existing profiles, source/held-photo
   context, Learn controls/photos and Map/snapshot scope on disposable data.
3. A fresh, verified production snapshot restored only into a new review
   directory. Existing ordinary files remain stable through copying; each SQLite
   online backup is individually consistent, not one global transaction.
4. An image built from the then-live immutable image plus only the committed
   runtime delta. Existing data is preserved; startup may add only missing
   versioned import files. Retain a manifest of those additions and collisions.
5. One guarded offline preservation check: 1 GiB RAM, no swap, one CPU, 256 PIDs,
   no network or published ports, read-only root and a 600-second limit. Compare
   all original accounts, records, database rows, private state and profiles.
   Use fictional accounts only; preserve Chris.H's real first-login state.
6. Exact-container cleanup, unchanged live release/image/mounts and public health.

The PR description and private durable checklist retain the exact-head receipts
after each check actually completes. Do not claim a rehearsal, timing, browser
interaction or human approval before it occurs. Production is not switched by
preparing this branch. Any intended release requires its own human approval,
fresh release-time backup, retained mounts/settings and rollback.

165 matched occurrences and 1,699 needing review. These are not distinct approved
cultivars or a census of the web. Public-profile gaps remain 11 photos, 13 rights,
33 cited traits and ten company links. Current/historical portfolios, 32 unclear
photo cells, the independent expected-name worksheets, photo identity/reuse,
current official rights, growing-region evidence and additional Learn/media and
market-statistics coverage remain open. This release does not certify them.

The protected expansion guide, canonical entities/Evidence/Facts/relationships,
schemas, CPVO and variety footprints, Trade/Weather normalization, raw boundary
geometry and published market-reference seed remain unchanged. Existing
Workspaces, lists, marks, research and review state remain collaborative; only
