# Executive Demo Runbook

Use the production interactive instance at `https://intel.johnnyaceii.com`.
The sequence is intentionally bounded to public, already-published evidence.

## 5–8 minute path

1. **Start with News (`/today`, 60 seconds).** Show the seven-day default,
   then set Berry to Blueberry. Open **More filters** once, point out the active
   count, and use **Clear all**. Do not trigger a live refresh during the demo.
2. **Open a story (60–90 seconds).** Select a card without leaving the feed.
   Point out the source-family label, captured text/fallback disclosure,
   prominent **Open original evidence**, and preserved URL state. Save it, then
   use thumbs-up to create an untrusted extraction candidate. Do not confirm a
   claim unless it has been rehearsed.
3. **Show provenance and trust (45 seconds).** Explain that thumbs-up ranks and
   proposes; only explicit analyst confirmation creates trusted dossier
   content. Close the reader and show that the feed position and filters remain.
4. **Open Fall Creek’s dossier (90 seconds).** Visit
   `/entities/company/company-fall-creek-farm-and-nursery`. Expand **Inspect
   monitoring expression**. Show canonical/alias matching, contextual handling
   of weak terms, exclusions, and why each item matched.
5. **Show the signal universe (60 seconds).** In the same dossier, show real
   public **NEWS**, **COMPANY SIGNAL**, **REPORT**, and **PODCAST** cards. Use
   the Lucentlands podcast as the spoken-media example. Every card retains an
   original evidence link; no LinkedIn scraping is involved.
6. **Open a Variety (45 seconds).** Use the hamburger on mobile or sidebar on
   desktop to open **Variety Database**, then a representative variety. Point
   out evidence coverage and that absence remains an explicit gap, not a score.
7. **Close on expansion (30 seconds).** Open the mobile drawer to show Today,
   Live Intelligence, Companies, Varieties, Geographies, reports/research, and
   decision surfaces share the same evidence and entity backbone.

## Safe fallback

- If an external publisher is slow or blocked, stay in the native reader and
  use its captured text or explicit metadata-only state. Do not retry live
  collection on stage.
- If the selected item has no body, show **Open original evidence** and explain
  the honest fallback rather than implying full-text capture.
- If Ask Berry OS or an external provider is unavailable, skip it. The core
  demo has no external-AI dependency.
- If a write action is undesirable, omit Save/thumbs-up and continue with the
  already-published Fall Creek dossier.
- The optional map is intentionally not in this demo. Use **Geographies** as
  the accessible corpus entry point instead.

## Rehearsal checks

- Use an iPhone-sized viewport once and desktop once.
- Confirm the Fall Creek dossier includes Podcast plus at least two other
  source families.
- Confirm Close and browser Back return to the same feed state.
- Never expose the deployment environment, credentials, or private inbox data.
