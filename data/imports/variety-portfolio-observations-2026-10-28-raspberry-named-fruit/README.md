# Source-labeled color fruit references

The issuer's Malaika and Zawadi product pages each provide a 300px color fruit
image with a same-name HTML image title beside the focal variety heading. The
images were downloaded and visually checked; logos and generic berry pictures
are excluded. The original image `alt` attributes are empty, so provenance records
the actual `title` attribute, without claiming an alt-text label.

These two exact-name source references can appear on the existing profiles while
their pixels remain hidden by default. Both retain attribution and unknown reuse
status. A private session choice does not publish the image or approve a reuse
license. Neither adds a patent association, legal-name alias, company role, trait
or growing footprint. Image bytes and original HTML remain in ignored storage.
