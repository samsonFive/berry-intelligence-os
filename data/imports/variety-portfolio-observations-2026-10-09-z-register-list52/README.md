# Register List 52: quoted cultivar headings

Body-free, unreviewed name observations from the original 2024 journal copy
hosted by New Mexico State University. All four berry sections and their
addenda are included. The filename sorts after the earlier same-day imports
so adding this snapshot does not change their first source references.

Eight sections account for 398 quoted first-name heading contexts: 388
described-entry/correction observations, eight quoted referrals and two
held I/l code glyphs. América's extracted accent placeholder was checked
against the original rendered heading. PDF page links accompany each name.

This bounded intake excludes body/parent/comparator mentions and unquoted
trade-name referrals. Sections remain partial. It is not complete source
recall, a global census or a current company portfolio. No company roles,
aliases, canonical varieties, source acceptance, traits, regions, current
rights or photo permissions are approved. The journal is not an official
rights registry; its historical citations require original-document checks.

verification. The original PDF, extracted text and full-page renders remain
