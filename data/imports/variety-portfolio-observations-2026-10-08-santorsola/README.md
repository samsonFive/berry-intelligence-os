# Sant’Orsola: bounded original-source name check

The live [breeding page](https://www.santorsola.com/sperimentazione-e-breeding/)
was read in the native browser on October 8, 2026. Its current raspberry and
strawberry list names Delfi and ten raspberry labels. The Italian crop words
are headings, not part of each variety name. Original spelling and the exact
name-specific technical-sheet links are retained.

These observations use the existing private discovery/review path. They do
not create canonical varieties, aliases, roles, rights, traits or growing
regions. The page’s patent wording is an unchecked company claim. Program
history and PDF URL directories are not publication dates. The third section
keeps the technical-document/photo/rights follow-up visible; it is not a
completed lifetime portfolio check. No photo asset is attributed to a named
variety from the hero image, diagram or general crop graphics.
