# Raspberry original documents

Four original US grant documents cover the literal denominations ABB 128,
ABB 132, ABB 135 and ABB 136. Links open their inspected claims on PDF page 3.
Four source-labeled fruit figures remain held for reuse review; the available
linked PNGs are low-resolution monochrome source thumbnails.

Twelve parent/comparison occurrences remain in separate context sections.
Numeric selections are source labels, not newly approved cultivars. Both
211150-009 and 211150-9 are retained because the ABB 135 document uses both
spellings. Parent/comparator records inherit no focal patent metadata or photos.

The January 2024 issuer announcement separately records Malaika / ABB135,
Zawadi / ABB136 and Baridi / ABB132. The retained 2025 Baridi / ABB 137 conflict
is not resolved. Allberry B.V., named applicant/assignee in the originals, is not
automatically merged with the Advanced Berry Breeding organization.

All nine sections and nineteen name occurrences remain unreviewed. No canonical
variety, alias, company, role, region, trait, current-rights conclusion or reuse
permission is created. CPVO priority references are application claims, not
verified European grants. Original PDFs, HTML, image bytes and rendered inspection
pages stay in ignored local storage; the repository contains metadata and links.
