# Fruitist blueberry source observations from Peru

Three source sections add 14 observations for the existing Agrovision Corp.
(Fruitist) company record. These are source name occurrences, with repeats across
documents preserved as separate provenance.

- UPN identifies Ventura and Emerald in a jam project that used blueberries
  supplied by Agrovision. [Proyecto MER](https://ciaa.upn.edu.pe/proyectos/proyecto-mer/?lang=en)
- The June 30, 2024 Red Agro Huancavelica bulletin pairs SEKOYA BEAUTY with
  FCM12-097 in the Agrovision Perú SAC row for Lambayeque. The rendered PDF table
  on page 4 confirms the columns and the site label A9 - 1.
  [June 2024 bulletin](https://www.drahuancavelica.gob.pe/images/pdf/Rediagro/blJun24.pdf)
- Figure 11 of Condorcahuana Puse's 2024 UNPRG report provides 11 distinct
  packing-table labels. Direct retrieval failed, so this section uses the
  indexed table text and remains partial. EB 846 and SEKOYA BEAUT need
  confirmation against the figure image.
  [UNPRG professional report](https://repositorio.unprg.edu.pe/bitstream/handle/20.500.12893/13614/Condorcahuana_Puse_Edwin_German.pdf?isAllowed=y&sequence=1)

The UPN samples, the historical site listing and the packing examples support
different company associations. The observations enter the existing private
review workflow. The current company portfolio, rights and commercial scale
still need independent evidence.
